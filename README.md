Project Overview  
This project implements a complete data workflow using an e-commerce dataset from kaggle.  
  
It includes:  
- Data cleaning and transformation (ETL)  
- Data modeling (Star Schema)  
- Exploratory Data Analysis (EDA)  
- Data visualization with Power BI  
- API development (Flask)  
  
Technologies used:  
- Python(Pandas)  
- MySQL  
- SQLAlchemy  
- Flask  
- Power BI
